### Rhythmic Proximity
**Analysis of IOI ratios using a periodicity-based proximity function:**

In this repository, inter-onset intervals (IOIs) of synthetically generated rhythmic sequences and real data from three animal species (*C. perspicillata*, *P. macrocephalus*, *Scorpaena spp.*) are analyzed using a specially developed, Gaussian-based 'proximity function' and compared to null models. The aim is to quantify the degree of rhymicity between IOI pairs following the assumption that small integer ratios between IOIs resemble a fundamental property of rhythmic structures.

---

### Repository Structure:

The repository contains three main components:

#### 1) Library (`proximitylib/`)
This folder contains the core Python functions for the analysis:

- **Proximity function:** Gaussian-based evaluation of IOI ratios for quantifying rhythmic proximity.
- **Parameter-sets:** A dictionary containting three Parameter combinations with different sensibilitys for the Proximity function, intendend for different questions about rhymicity.
- **Null models:** Function to generate a set of null sequences drawn from exponential and uniform IOI distributions for statistical comparison.
- **Peak analysis:** Computation of peak significance for individual sequences or entire datasets.

#### 2) Application Code (`code/`)
Python scripts that apply the library functions to different datasets and experimental conditions:

- **Single sequence visual analysis (`catalogue.ipynb`):** Analysis of a single sequences using the Proximity function which computes a "catalogue page" with multiple plots to visualise Rhythmic Proximity in this single sequence.
- **Function explorer (`function_explorer.ipynb`):** A widget tool that a visualises how the Proximity curve changes when adjusting single parameters.
- **Analysis for Rhythmic complexity (`peak_tables.ipynb`):** Detection of single ratios which appear more often/more precise in a given sequence or dataset than expected by nullmodels.
- **Visualizations (`paper_plots.ipynb`):** This file contains further code used to generate the plots featured in the paper.

#### 3) Data (`data/`)
Processed CSV files containing IOIs from:

- Animal vocalizations:
  - Kwa-Sounds (*Scorpaena spp.*)
  - Seba's short-tailed bat (*Carollia perspicillata*)
  - Sperm whale (*Physeter macrocephalus*) codas
- Theoretical secuences generated by `test-sequence_generator.py`
  - For a detailed description of the data used for the proof of concept see **Table S1** in the paper.

For the functions to work each CSV file has to include at least one column `IOI` (inter-onset interval in milliseconds or seconds), which is used as input for the proximity analysis.

#### 4) Single sequence analysis catalogue (`catalogue_pages/`)
A set of "catalogue pages" computed by `catalogue.ipynb` of all sequences discussed in the paper.
