### Rhythmic Proximity
**Analysis of IOI ratios using a periodicity-based proximity function:**

In this repository, inter-onset intervals (IOIs) of synthetically generated rhythmic sequences and real data from three animal species (*C. perspicillata*, *P. macrocephalus*, *Scorpaena spp.*) are analyzed using a specially developed, Gaussian-based 'proximity function' and compared to null models. The aim is to quantify the degree of rhymicity between IOI pairs following the assumption that small integer ratios between IOIs resemble a fundamental property of rhythmic structures.

---

### Repository Structure:

The repository contains three main components:

#### 1) Library (`proximitylib/`)
This folder contains the core Python functions for the analysis:

- **Proximity function:** Gaussian-based evaluation of IOI ratios for quantifying rhythmic proximity.
- **Parameter sets:** A dictionary containing three Parameter combinations with different sensibilitys for the Proximity function, intended for different questions about rhymicity.
- **Null models:** Function to generate a set of null sequences drawn from exponential and uniform IOI distributions for statistical comparison. A third null model, which resamples IOIs randomly from the given dataset, is included but was not included in the main text.
- **Peak analysis:** Computation of peak significance for individual sequences or entire datasets.

#### 2) Application Code (`code/`)
Python scripts that apply the library functions to different datasets and experimental conditions:

- **Single sequence visual analysis (`catalogue.ipynb`):** Analysis of a single sequence using the Proximity function, which computes a “catalogue page” with multiple plots to visualize Rhythmic Proximity in this single sequence.
- **Function explorer (`function_explorer.ipynb`):** A widget tool that visualizes how the Proximity curve changes when adjusting single parameters.
- **Analysis for Rhythmic complexity (`peak_tables.ipynb`):** Detection of single ratios which appear more often/more precisely in a given sequence or dataset than expected by null models.
- **Visualizations (`paper_plots.ipynb`):** This file contains further code used to generate the plots featured in the paper.

#### 3) Data (`data/`)
Processed CSV files containing IOIs from:

- Animal vocalizations:
  - Kwa-Sounds (*Scorpaena spp.*)
  - Seba's short-tailed bat (*Carollia perspicillata*)
  - Sperm whale (*Physeter macrocephalus*) codas
- Theoretical sequences generated by `test-sequence_generator.py`
  - For a detailed description of the data used for the proof of concept, see **Table S1** in the paper.

For the functions to work, each CSV file must include at least one `IOI` (inter-onset interval in milliseconds or seconds) column, which is used as input for the proximity analysis.

#### 4) Single sequence analysis catalogue (`catalogue_pages/`)
A set of "catalogue pages" computed by `catalogue.ipynb` of all sequences discussed in the paper.

### Installation and execution

#### 1. Install dependencies

Install the required Python packages from the repository root:

```bash
python -m pip install -r requirements.txt
```

Make sure that Jupyter Notebook or JupyterLab is available if you intend to run the analysis notebooks.

#### 2. Generate synthetic sequences (optional)

The repository includes the synthetic datasets used in the analyses. If these datasets are already available, this step can be skipped.

To regenerate the synthetic sequences, run `test-sequence_generator.py` from the repository root. The script saves the generated CSV files to `data/theoretical_sequences/`.

Random seeds should be configured consistently to reproduce the same synthetic datasets.

#### 3. Run the analysis notebooks

Open the notebooks in the `code/` directory and execute them using a Python environment with the required dependencies installed.

The notebooks import the functions from `proximitylib/proximity.py` as needed. The library does not normally need to be executed separately.

The notebooks can be run independently, depending on the analysis of interest:

* `catalogue.ipynb` generates visual catalogue pages for individual sequences.
* `function_explorer.ipynb` interactively explores the proximity-function parameters.
* `peak_tables.ipynb` performs peak analyses and generates summary tables.
* `paper_plots.ipynb` generates the visualizations used in the paper.

Run each notebook from the working directory expected by its relative file paths. For a complete reproduction of the paper, use the datasets, parameter settings, and analysis procedures documented in the accompanying paper and supplementary materials.
